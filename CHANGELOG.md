# Changelog

## 1.1.0
- New settings: `LiftPortalBlock`, `Rounding`, `FreeAllowance`, `ItemOverrides`, `Message`, `MessageText`.
- `TollFreePortals` is replaced by `TollStonePortals` and `TollTeleportAllWorlds`. If you had turned it off, turn these two off.
- Settings are grouped into sections, so values changed in 1.0.0 need to be set again.
